How to use this map

Products and features

A product is a purchasable licence, such as Microsoft 365 Business Standard or E5.

A feature (service plan) is a capability bundled inside products, such as Exchange Online or Microsoft Teams.

Use By product to see what a licence includes. Use By feature to see which licences include a capability. Click any item to cross over to the other view.

Searching

Typing matches any part of a name by default. Search runs across product names, feature names, SKU codes, and GUIDs.

"exact phrase" matches the whole name only.

* matches any run of characters, for example defender*endpoint.

? matches a single character.

Toggles

Show all products reveals every SKU, including add-ons. Show SKU codes and GUIDs displays the underlying identifiers.
